# osmaRef
Your all-in-one referee client. ~~(yeah same as [wyReferee](https://github.com/wesley-221/wyReferee))~~

This client works on both stable and lazer, so you don't need another IRC client anymore.

Currently only support Windows. May support mac and linux soon. (Not until I release v1.0.0 or get a mac.)

## Features

* Support both stable and lazer
* Easy import tournaments from `bracket.json` and [Mayumi](https://mayumi.xyz)
* Unique "Win-by Rule" interpreter
* Discord webhook support
* Highly customizable message triggers
* Automatically check & sync scores from mplink
* lazer `!mp` commands compatibility (partly)

## How to use

1. Download `.exe (installer)` or `.zip (portable)` from [latest release](https://github.com/ApigeonAPE/osmaRef/releases/latest).
2. Run `.exe` and follow the install guidance, or unzip `.zip` to a directory like `D:\softwares\osmaRef`.
3. Run `osmaRef.exe`.
4. Login with your osu! account and IRC account.
5. Create or import a tournament.
6. Handle the refereeing.
